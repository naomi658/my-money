# 나의 가계부 (PWA)

쓴 돈은 간단하게 기록하고, **계좌·카드·대출까지 합친 순자산**을 한눈에 보는 가계부 웹앱입니다.
아이폰 사파리에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요. 인터넷 없이도 열립니다.

- 주소: https://naomi658.github.io/my-money/ *(저장소 Pages를 켠 뒤)*

## 무엇이 되나요

### 내역 — 하루하루 기록
- 지출 / 수입 / **이체**(계좌 간 이동)를 한 화면에서 입력. 금액은 숫자 키패드로 바로.
- 카테고리(식비·카페·교통·쇼핑·생활·주거·통신·의료·문화·여가·선물·교육 + 월급·용돈·부수입 …)를 고르고,
  입력 화면에서 **새 카테고리를 바로 추가**할 수 있어요.
- 월 달력에 날짜별 **수입/지출 합계**가 표시되고, 날짜를 누르면 그 날 내역이 아래에 나옵니다.
- 상단 요약: 이번 달 수입 · 지출 · 남은 돈, 그리고 **현재 순자산**.
- **검색**: 메모·카테고리·계좌·금액으로 모든 달의 기록을 찾고, 종류/계좌로 걸러 볼 수 있어요.
- **예산**: 월 총예산 + 카테고리별 예산, 진행률 바.
- **고정비**: 월세·구독·월급처럼 매달 같은 돈을 등록해 두고 `한 번에 넣기`로 그 달 기록을 만들어요.

### 통계 — 한눈에 보는 소비
- 카테고리별 **도넛 차트** + 목록(비율·금액·**전월 대비 증감**).
- **최근 6개월 수입·지출** 막대 차트와 달마다 남긴 돈(순저축).
- **결제수단별 지출**(체크·신용카드·현금 …), 수입 구성.
- 모든 차트는 SVG로 직접 그려서 **외부 라이브러리·CDN 없이 오프라인에서도** 동작합니다.

### 자산 — 진짜 하고 싶었던 것
- **순자산 = 총 자산 − 부채**를 맨 위에 크게. 지난달 대비 변화도 함께.
- **자산 구성 비율** 도넛, **최근 12개월 순자산 추이** 차트와 월별 표.
- 계좌 유형: 입출금 · 예·적금 · 투자 · 현금 · 기타 자산 / **신용카드 · 대출**(부채).
- 계좌 추가·이름/종류 수정·**잔액 수정**(과거 기록은 그대로 두고 시작 잔액만 조정)·
  순서 바꾸기·숨기기·삭제.
- **자동 연동**: 지출을 기록하면 그 계좌 잔액이 줄고, 수입은 늘고, 이체는 보내는 계좌에서 받는 계좌로 옮겨집니다.
  신용카드로 쓰면 **미결제 부채**로 쌓이고, 카드 행의 `납부` 버튼(또는 계좌→카드 이체)으로 정산됩니다.

### 설정 — 백업과 관리
- **JSON 내보내기/불러오기**: 가계부·자산·예산·카테고리·고정비 전체 백업. 불러올 때 **덮어쓰기 / 합치기** 선택.
- **CSV 내보내기**: 엑셀·구글 스프레드시트에서 바로 열리는 UTF-8 CSV.
- **CSV 가져오기**: 위플 머니·은행·엑셀에서 내보낸 CSV를 **컬럼을 직접 맞춰** 불러옵니다.
  - 쉼표/세미콜론/탭 자동 구분, 따옴표 안 쉼표·줄바꿈 처리
  - `날짜` + `금액`(부호 또는 지출/수입 컬럼), `구분`, `카테고리`, `결제수단`, `메모`, `받는 계좌(이체)`
  - 금액이 모두 양수면 **지출**로, 음수가 섞여 있으면 **부호대로** 해석(직접 바꿀 수 있어요)
  - 없는 카테고리·계좌는 이름을 보고 **자동으로 만들어** 줌(카드/현금/적금/대출도 알아서 구분)
  - 같은 기록을 다시 불러와도 **중복되지 않음**
- 카테고리 관리, 고정비 관리, 예산 설정, 샘플 데이터, 전체 초기화.

## 기록은 어디에 저장되나요

앱에는 **실제 개인 기록이 전혀 들어 있지 않습니다.** 입력한 내용은 그 브라우저의
`localStorage`(`mymoney-v1`)에만 저장되고 서버로 전송되거나 저장소에 올라가지 않습니다.
브라우저 데이터를 지우면 함께 사라지니, 가끔 **설정 → JSON으로 내보내기**로 백업해 주세요.

처음 실행하면 **샘플 데이터로 둘러보기**와 **빈 상태로 시작하기** 중에 고를 수 있고,
샘플은 기능을 둘러보기 위한 가상의 예시일 뿐 실제 사용자 데이터가 아닙니다.

## 아이폰에 설치

1. 사파리에서 주소를 엽니다.
2. 아래 **공유** 버튼 → **홈 화면에 추가**.
3. 홈 화면의 아이콘으로 실행하면 주소창 없이 앱처럼 열립니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조와 스타일 (PWA 메타 태그 포함) |
| `core.js` | 데이터 모델·계산 (잔액 연동, 순자산, 통계, 예산, 고정비, CSV/JSON) |
| `app.js` | 화면 렌더링, 입력·시트, 이벤트, 저장 |
| `manifest.json` | PWA 매니페스트 |
| `sw.js` | Service Worker — 화면·코드는 네트워크 우선, 실패 시 캐시 |
| `icon-180.png` `icon-192.png` `icon-512.png` | 앱 아이콘 |

## 배포

```bash
# 저장소를 만든 뒤 (Pages: main / root)
git remote add origin https://github.com/naomi658/my-money.git
git push -u origin main
```

Pages가 켜지면 https://naomi658.github.io/my-money/ 에서 열립니다.
